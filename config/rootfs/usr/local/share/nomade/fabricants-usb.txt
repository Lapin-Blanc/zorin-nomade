# Fabrique-Clé — identifiants de fabricants USB (VID) connus, pour l'onglet Diagnostic.
#
# Format : VID (hexadécimal) ou VID:PID (un modèle précis)  rôle  nom
# Rôles :
#   marque      fabricant de clés ou de SSD : le VID ne dit rien de la puce utilisée
#   controleur  fabricant de contrôleurs de clés : la marque a laissé l'identifiant de la puce
#   pont        pont USB vers SATA ou NVMe : presque toujours un vrai SSD derrière
#   suspect     identifiant fantaisiste, typique des clés anonymes ou contrefaites
#   ssd         (modèles) contrôleur de SSD qui parle USB directement, sans pont
#
# Le VID est celui de l'entreprise qui a enregistré le produit auprès de l'USB-IF. Une marque peut
# changer de contrôleur d'une série à l'autre sans changer de VID : ce n'est qu'un indice.
